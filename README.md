# Media Slideshow

上傳多張**相片與影片**、背景音樂，自訂播放秒數，全螢幕循環播放。

## 功能

- 同時支援相片（JPG / PNG / GIF / WebP）與影片（MP4 / WebM / MOV）
- 拖曳或點擊上傳，可一次選多個
- 相片可自訂播放秒數；影片預設播完整支，也可指定秒數截斷
- 背景音樂（可調音量、靜音）
- 全螢幕播放
- 循環播放、淡入淡出、進度條
- 鍵盤：`←` `→` 切換、空白鍵暫停、`F` 全螢幕、`M` 靜音、`Esc` 結束
- 純前端，媒體只存在瀏覽器記憶體

## 使用方式

1. 開啟網站
2. 上傳相片與／或影片
3. （可選）選擇背景音樂
4. 調整各項目播放秒數
5. 按「開始播放」

## 啟用 GitHub Pages

1. Repo → **Settings** → **Pages**
2. Source：**Deploy from a branch**
3. Branch：`main` / `/ (root)`
4. Save
